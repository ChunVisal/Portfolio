## 📌 Features

### 🖥️ Modern Frontend

- Built with **Vue 3** & **Vite**
- Fully responsive UI
- Smooth animations, transitions, and clean design
- Mobile-first architecture

### ⚙️ Backend API (Node.js + Express)

- Stores comments into a local **JSON file**
- Simple and fast API endpoint:
  - `POST /add-comment`
- No database required
- Clean server structure, deployable to **Render**

### 🌐 SEO Optimized

- Custom favicon  
- Fast loading time  

### 🎨 Design System

- Tailwind-inspired utility classes  
- Exo 2 & Lato fonts  
- Handmade components with UI consistency
